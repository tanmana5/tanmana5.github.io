This is a placeholder first post so the blog index isn't empty. Feel free to delete it.

A few things I'd like this space to be:

- **A scratchpad for ideas I'm not ready to publish.** Half-baked thoughts on
  LLM agents, planning, and where I think research is heading.
- **A reading log.** Short notes on papers I found interesting — what worked,
  what didn't, what I'd want to try.
- **A place to write more freely than a paper allows.** Discussions about why a
  certain framing matters, what failed in an experiment before it worked,
  the messy middle that doesn't fit into a conference submission.

To write a new post, drop a Markdown file in `_posts/` named
`YYYY-MM-DD-your-slug.md` with the same frontmatter as this one.
